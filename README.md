# Systems Administrator Home Lab

## About This Portfolio

Welcome to my Systems Administrator Home Lab!

This repository documents my hands-on technical projects using an Apple Mac M1, Oracle VirtualBox, and Red Hat Enterprise Linux 10 (RHEL 10 ARM64).

The purpose of this lab is to develop practical IT infrastructure skills through system administration, Linux security, networking, automation, and troubleshooting.

## Lab Environment

| Component | Configuration |
|---|---|
| Host Computer | Apple Mac M1 |
| Host Operating System | macOS |
| Virtualization | Oracle VirtualBox |
| Guest Operating System | Red Hat Enterprise Linux 10 |
| Architecture | ARM64 (aarch64) |
| Host Memory | 8 GB |
| Scripting | Bash |
| Version Control | Git and GitHub |
