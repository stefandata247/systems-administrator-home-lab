# Project 01: RHEL 10 System Inventory

## Project Overview
This project demonstrates basic Linux system administration and hardware inventory management using Red Hat Enterprise Linux 10.

## Lab Environment
- Operating System: RHEL 10
- Architecture: ARM64 (aarch64)
- Host Machine: Apple Mac M1
- Virtualization: VirtualBox

## Objectives
- Identify Linux operating system information.
- Inspect CPU architecture and processor details.
- Check available RAM.
- Inspect disk storage.
- Review system uptime and kernel version.

## Commands Used

```bash
cat /etc/redhat-release
uname -a
lscpu
free -h
lsblk
df -h
uptime
hostnamectl
```

## Skills Demonstrated
- Linux command-line administration
- Hardware inventory
- System monitoring
- Linux troubleshooting
